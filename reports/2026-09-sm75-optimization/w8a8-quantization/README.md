# 支线一：W8A8 权重量化 — ✅ 推荐（本轮最大收益）

## 结论

权重从 FP8 切到 W8A8（imatrix）是 2026-09 战役的最大单项收益：TTFT -19%~-35%，prefill +24%~+54%。
整体最优变体 W1（W8A8 + FP16 KV + 65K + MTP3）；需 180K 长上下文时用 W7（W8A8 + FP8 KV + 180K + MTP3）。

## 变体配置

| 变体 | 权重 | KV Cache | max-model-len | MTP |
|---|---|---|---|---|
| B0（重测） | FP8 | FP8 (fp8_e4m3) | 180,000 | 3 |
| W1 | W8A8 (imatrix) | FP16 | 65,536 | 3 |
| W7 | W8A8 (imatrix) | FP8 (fp8_e4m3) | 180,000 | 3 |
| W9 | W8A8 (imatrix) | INT8 (per_token_head) | 180,000 | 3 |
| W10 | W8A8 (imatrix) | FP8 (fp8_e4m3) | 180,000 | 4 |

## 实测数据（TTFT s / Prefill tok/s / Decode tok/s，128-token 流式口径）

| 档位 | B0 | W1 | W1 vs B0 | W7 | W9 | W10 |
|---|---|---|---|---|---|---|
| S (2.84K) | 2.59 / 1,097 / 98.6 | 2.08 / 1,365 / 82.3 | **-20%** | 2.13 / 1,337 / 76.6 | 2.23 / 1,277 / 73.6 | 2.19 / 1,303 / 77.6 |
| M (8.45K) | 6.37 / 1,328 / 115.1 | 4.39 / 1,928 / 79.1 | **-31%** | 4.48 / 1,888 / 83.7 | 5.54 / 1,526 / 62.3 | 4.69 / 1,803 / 92.8 |
| L (19.77K) | 14.92 / 1,325 / 90.4 | 9.71 / 2,037 / 79.4 | **-35%** | 10.11 / 1,956 / 66.3 | — | 10.45 / 1,892 / 92.6 |
| XL (59.24K) | 52.98 / 1,118 / 92.4 | 35.76 / 1,656 / 66.7 | **-33%** | 37.73 / 1,570 / 75.6 | — | 38.75 / 1,529 / 71.5 |

注：

- B0 与 W1 的 KV/上下文条件不对齐（FP8/180K vs FP16/65K），同条件对比是 B0 vs W7（XL 52.98→37.73s，-29%）。
- Decode 略慢于 FP8 基线（XL 128-token 口径 66.7 vs 92.4 tok/s）；W4A16 在 decode 更强（见 awq-w4a16 支线）。
- W9（INT8 KV）有冷启动异常（S 档 run1/2 达 28.5s/59.1s，取 run3）且未跑 L/XL，判负优化，详见 int8-kvcache 支线。
- W10（MTP4）深层接收率坍缩（38.9% vs MTP3 的 62.9%），判负优化。
- **W8A8 未做业务侧质量回归，切换前需评测。**
